🍽️ QR Ordering System

A modern QR-based restaurant ordering system that allows customers to scan a QR code, browse menus, and place orders directly from their devices without waiting for a waiter.

✨ Features

- 📱 QR Code Table Ordering
- 🍔 Digital Restaurant Menu
- 🛒 Real-Time Cart System
- 📦 Order Management
- ⚡ Fast and Responsive UI
- 🔒 Secure Environment Variables
- 🤖 Gemini AI Integration
- 📊 Admin Dashboard
- 🌐 Mobile Friendly Design

---

📸 Overview

QR Ordering System is designed to help restaurants, cafés, food courts, and small businesses digitize their ordering process.

Customers simply:

1. Scan QR Code
2. Open Digital Menu
3. Select Food & Drinks
4. Place Order
5. Wait for Confirmation

Restaurant staff can manage incoming orders through the dashboard in real time.

🚀 Installation

Clone the repository:

git clone https://github.com/Strong-Bee/QR-Ordering-System.git

Enter the project folder:

cd QR-Ordering-System

Install dependencies:

npm install

Create environment file:

cp .env.example .env.local

Add your Gemini API Key:

GEMINI_API_KEY=your_api_key_here

Start development server:

npm run dev

---

⚙️ Environment Variables

Required variables:

GEMINI_API_KEY=your_gemini_api_key

---

🖥️ Running Production

Build project:

npm run build

Run server:

npm start
